Backpocket site desk

Edit the zine site.

Changes are saved straight to your GitHub repository, and the live site updates a minute or two later. ← Back to the site

1 · Connect to GitHub

Only someone with your GitHub access token can save changes here. The token stays in this browser only. Use your own device, and press “Disconnect” on a shared one.

2 · Your site: click anything to edit it

How it works: this is your real site. All text has an orange dotted outline: hover to see its name, click and type. Images (the cover art, the issue picture and every gallery photo) also have an outline: click an empty part of one to replace it. Nothing goes live until you press Publish changes.

3 · Colours

Changes show in the preview straight away.

4 · Images

Files over about 8 MB load slowly for visitors. iPhone HEIC photos are converted to JPG because browsers can’t show HEIC.

Cover picture (top of the page)

Replaces the paper-collage cover artwork. Remove it to bring the artwork back.

Issue picture

Shown next to the issue description, in its full proportions.

Gallery photos

Use the arrows to reorder. To swap a photo, click it in the preview.

5 · Release countdown

Write {date} where the date should appear and {days} where “47 days” should appear.
