Backpocket site desk

Edit the zine site.

Changes are saved straight to your GitHub repository, and the live site updates a minute or two later. ← Back to the site

1 · Connect to GitHub

Only someone with your GitHub access token can save changes here. The token stays in this browser only. Use your own device, and press “Disconnect” on a shared one.

2 · Your site: click the text to edit it

How it works: this is your real site. Every piece of text you can change has an orange dotted outline. Hover to see its name, click it and type. Nothing goes live until you press Publish changes.

3 · Main issue photo

Shown next to the issue description, in its full proportions. Leave empty to keep the paper-collage artwork.

4 · Gallery photos

Very large files (over about 8 MB) load slowly for visitors. Phone photos in HEIC format get converted to JPG because browsers can’t show HEIC. Use the arrows to reorder.
